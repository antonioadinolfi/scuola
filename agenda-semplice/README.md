# Calendario impegni semplice

Pagina web autonoma, senza database e senza login.

Funzioni:
- calendario mensile;
- inserimento manuale di impegni;
- inserimento tramite dettatura vocale del browser;
- lettura di PDF testuali con estrazione automatica di righe data/ora;
- modifica, completamento ed eliminazione;
- ricerca;
- stampa;
- backup/ripristino JSON;
- salvataggio locale nel browser.

I dati rimangono nel browser/dispositivo. Per una futura sincronizzazione tra PC e telefono sarà necessario aggiungere un backend o un servizio cloud.

Nota PDF: i PDF composti da immagini/scansioni non contengono testo estraibile; per quelli servirà una fase OCR.
