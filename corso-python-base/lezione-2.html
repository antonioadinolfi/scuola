1 · Le variabili

Un nome per ogni dato

Una variabile è un nome che il programma usa per ricordare un valore. Si crea con l’assegnazione: eta = 17 si legge «assegna 17 a eta». Il segno = in Python non è un’uguaglianza matematica: prende il valore a destra e lo associa al nome a sinistra. Per questo x = x + 1 ha senso: calcola x + 1 e mette il risultato in x.

Il visualizzatore esegue il programma della slide una riga alla volta: premi ▶ Esegui passo passo, poi Avanti ▶. A destra vedi le variabili in memoria con il loro tipo; le righe colorate di verde sono appena cambiate.

Le regole per i nomi

  • contengono lettere, cifre e il trattino basso _;
  • non iniziano con una cifra e non contengono spazi;
  • non sono parole riservate come if o else; evita anche i nomi delle funzioni, come print o input.
  • ✓ base, altezza_max, voto2, età
  • ✗ 2voto, altezza max, if
  • Scegli nomi che spiegano il contenuto: area è meglio di a.
Python è case-sensitive. Distingue le lettere minuscole dalle maiuscole: nome, Nome e NOME sono tre variabili diverse. Esegui l’esempio e leggi l’errore, poi correggilo.
1 · I tipi di dato

int, float, str, bool

Ogni valore ha un tipo, che stabilisce che cosa si può fare con quel valore. I principali tipi di dato sono int, float, str e bool.

int intero

Numeri senza parte decimale, positivi o negativi: 17, -4, 2026. In Python possono essere grandi a piacere.

float decimale

Numeri con il punto decimale: 4.7, 10.0, -0.5, 3e2 (cioè 300.0).

str stringa

Testo tra virgolette singole o doppie: 'Anna', "10.0", "" (stringa vuota).

bool booleano

Solo due valori: True e False, con la maiuscola e senza virgolette. Servono nelle condizioni (Lezione 4).

L’interprete di Python riconosce il tipo di dato a runtime, cioè al momento dell’esecuzione del codice, guardando il valore: non bisogna dichiararlo. Per sapere il tipo di un valore si usa la funzione type(). Scrivi un valore qui sotto e chiedi a Python di che tipo è.

Una variabile può cambiare tipo

In Python il tipo appartiene al valore, non alla variabile: la stessa variabile può contenere prima un intero, poi una stringa, poi un decimale. Guardalo nel visualizzatore.

tipizzazione dinamica e «debole»

Il libro di testo chiama questa caratteristica tipizzazione debole. Nella documentazione di Python e nei testi di informatica si dice più spesso tipizzazione dinamica: il tipo è deciso durante l’esecuzione e una variabile può cambiarlo. Python però non mescola i tipi da solo: "4" + 5 dà errore, mentre in linguaggi come JavaScript diventerebbe "45". Per questo si dice anche che Python è fortemente tipizzato: le conversioni le decide il programmatore.

2 · Leggere dalla tastiera

La funzione input()

input("messaggio") mostra il messaggio, aspetta che l’utente scriva qualcosa e prema Invio, poi restituisce ciò che è stato scritto. Negli editor di questo corso i dati da tastiera si scrivono nella casella gialla Input da tastiera, una riga per ogni input(): l’output li mostra come farebbe IDLE.

La funzione input() memorizza come stringa tutti i dati immessi da tastiera: per utilizzarli correttamente, perciò, occorre convertirli con int() (intero) o float() (decimale). Prova a cambiare i valori nella casella gialla.

Ora prova con base 1.1 e altezza 1.1: l’area risulta 1.2100000000000002! Non è un errore del programma: il computer rappresenta i decimali in binario e alcuni, come 1.1, non sono esatti. Nella Lezione 3 imparerai ad arrotondare l’output con format().

In sintesi

Che cosa porti a casa

  • Una variabile è un nome associato a un valore con =; il valore può cambiare durante l’esecuzione.
  • I tipi principali sono int, float, str, bool; l’interprete li riconosce a runtime e type() li mostra.
  • La stessa variabile può assumere tipi diversi (tipizzazione dinamica, detta «debole» nel libro).
  • Python è case-sensitive: nome e Nome sono variabili diverse.
  • input() restituisce sempre una stringa: per i calcoli si converte con int() o float().
