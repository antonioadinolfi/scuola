1 · Che cos’è Python

Un linguaggio intuitivo, facile da imparare e open source

Python è uno dei linguaggi di programmazione più usati al mondo: lo trovi nell’analisi dei dati, nell’intelligenza artificiale, nei siti web, nella robotica e nella didattica. Python è un linguaggio di scripting interpretato di alto livello, multipiattaforma e multi-paradigma. Seleziona ogni caratteristica per leggerne il significato.

La carta d’identità di PythonInfografica
Chi l’ha inventato. L’interprete di Python è stato scritto da Guido van Rossum, programmatore olandese, che cominciò a lavorarci alla fine del 1989; la prima versione pubblica uscì nel 1991. Il nome non viene dal serpente ma dal gruppo comico britannico dei Monty Python.
Dove si scrive il codice. Si può usare un normale editor di testo non formattato oppure un ambiente di sviluppo come IDLE, che si installa insieme a Python. Non si usa Word: aggiunge formattazione e virgolette «curve» che Python non capisce.
1 · Interprete e compilatore

Chi traduce il codice per il computer?

Il processore capisce solo il linguaggio macchina, fatto di 0 e 1. Un programma scritto in un linguaggio di alto livello va quindi tradotto. Ci sono due strategie:

Compilatore

Traduce tutto il programma in linguaggio macchina e produce un file eseguibile (ad esempio un .exe). Solo dopo il programma può essere eseguito. Esempi: C, C++.

Interprete

Legge il programma ed esegue un’istruzione dopo l’altra, senza produrre un eseguibile. Si scrive, si esegue, si corregge in un attimo. Esempio: Python.

    un dettaglio per i più curiosi

    In realtà Python, prima di eseguire un file, lo traduce velocemente in un codice intermedio (bytecode). Per questo gli errori di sintassi (una parentesi non chiusa, due punti mancanti) vengono segnalati subito, prima di eseguire qualsiasi riga. Gli errori come un nome sbagliato, invece, emergono solo quando l’esecuzione arriva a quella riga: è ciò che hai visto nella simulazione.

    2 · La shell e l’editor

    Un comando alla volta: la shell

    In IDLE, la finestra Shell mostra il prompt >>>: scrivi un’istruzione, premi Invio e Python risponde subito. È perfetta per provare. Ecco una shell vera, che funziona nella pagina: prova i comandi della slide o premi i pulsanti.

    Nella shell, se scrivi solo un’espressione (come 5*7), Python ne mostra il valore anche senza print. In un programma salvato su file, invece, senza print non compare nulla. L’ultimo comando contiene un errore voluto: leggi il messaggio.

    Un programma intero: l’editor e print()

    Per scrivere un programma vero si apre l’editor (in IDLE: File → New File), si scrivono più istruzioni, si salva il file con estensione .py e lo si esegue (Run → Run Module, tasto F5). Qui l’editor è già pronto: modifica il codice e premi ▶ Esegui (oppure Ctrl+Invio).

    print() è una funzione built-in, cioè già pronta in Python, che visualizza a schermo i suoi argomenti. Alcune regole da osservare nell’esempio:

    • il testo va tra virgolette, doppie "…" o singole '…': si chiama stringa;
    • senza virgolette, Python calcola l’espressione: 5 * 7 diventa 35, mentre "5 * 7" resta un testo;
    • più argomenti separati da virgole vengono stampati separati da uno spazio;
    • ogni print() va a capo alla fine.
    Attenzione agli errori. Python distingue maiuscole e minuscole: Print non è print. Se manca una virgoletta o una parentesi compare un SyntaxError: leggi la riga indicata, è quasi sempre lì il problema. Prova a togliere una parentesi nell’esempio 2 e premi Esegui.

    Esercizio 1 · Vero o falso?

    ★ Guidato
    • Un programma Python va compilato in un file .exe prima di poter essere eseguito.
    • Lo stesso programma Python può funzionare su Windows e su Linux.
    • Python è un software a pagamento della Microsoft.
    • Con un interprete, le righe che precedono un errore di esecuzione vengono eseguite.
    • Nella shell di IDLE si esegue un comando alla volta.
    • Print("Ciao") e print("Ciao") sono equivalenti.

    Esercizio 2 · Il tuo primo programma

    ★ Codice

    In sintesi

    Che cosa porti a casa

    • Python è un linguaggio di scripting, interpretato, di alto livello, multipiattaforma, multi-paradigma e open source; il suo interprete è stato scritto da Guido van Rossum a partire dal 1989.
    • Un compilatore traduce tutto il programma prima di eseguirlo; un interprete esegue un’istruzione alla volta.
    • La shell (>>>) esegue un comando alla volta; l’editor serve per scrivere e salvare programmi .py.
    • print() visualizza i suoi argomenti: il testo va tra virgolette, le espressioni senza virgolette vengono calcolate.
