    Glossario

    Le parole del corso

    Interprete
    Programma che legge il codice ed esegue un’istruzione alla volta; un compilatore invece traduce tutto il programma prima di eseguirlo.
    Shell ed editor
    La shell (>>>) esegue un comando alla volta; l’editor serve per scrivere e salvare un programma completo in un file .py.
    Variabile
    Nome associato a un valore con l’assegnazione =, ad esempio eta = 17.
    Tipo di dato
    int (interi), float (decimali, con il punto), str (stringhe, tra virgolette), bool (True e False).
    Tipizzazione dinamica
    Il tipo è deciso durante l’esecuzione e una variabile può cambiarlo; il libro la chiama «tipizzazione debole».
    Case-sensitive
    Python distingue maiuscole e minuscole: nome e Nome sono variabili diverse.
    input()
    Legge una riga dalla tastiera e la restituisce sempre come stringa.
    Conversione
    int() e float() trasformano una stringa in numero; str() trasforma un numero in stringa.
    // e %
    Divisione intera (quoziente) e modulo (resto): 17 // 5 = 3, 17 % 5 = 2.
    Concatenamento
    Con le stringhe + le unisce ("meta" + "dati") e * le ripete ("ab" * 3).
    Carattere di escape
    Sequenza che inizia con \ dentro una stringa: \n va a capo, \t inserisce una tabulazione.
    Indentazione
    Il rientro delle righe: in Python definisce i blocchi di codice di if, elif ed else.
    Operatori relazionali e logici
    == != < > <= >= confrontano due valori; and, or, not combinano le condizioni.
    elif
    «altrimenti se»: permette più di due rami con condizioni mutuamente esclusive.
