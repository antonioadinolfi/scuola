Area di Calcolo: Regressione Lineare
Ogni studente crea una copia personale del foglio nella cartella del docente e lavora solo sulla propria copia.
Apri in una nuova scheda

Come funziona

Questa versione è predisposta per usare un Google Apps Script Web App che crea la copia del modello direttamente nel Drive del docente, dentro una cartella dedicata, assegna il nome dello studente e condivide il file con lo studente in modifica.

  1. Lo studente inserisce nome e email scolastica.
  2. Clicca Crea la mia copia nel Drive del docente.
  3. La pagina chiama il Web App di Google Apps Script.
  4. Il Web App crea o recupera la copia personale nella cartella indicata dal docente.
  5. Il foglio viene aperto a destra in modalità completa.
Nota: un semplice file HTML non può creare da solo file nel tuo Drive. Serve necessariamente un backend Google Apps Script o API Google con OAuth.
