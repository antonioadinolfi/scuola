1 Classi, oggetti e self

Una classe è il progetto, un oggetto è un esemplare costruito con quel progetto. Quando scrivi Lampada('rossa'), Python crea un nuovo oggetto ed esegue subito il metodo __init__, che prepara gli attributi.

Dentro i metodi, self è l'oggetto su cui è stato chiamato il metodo: in a.accendi(), self è a.

Esempio 
class Lampada:
    def __init__(self, colore):
        self.colore = colore
        self.accesa = False

    def accendi(self):
        self.accesa = True

    def descrivi(self):
        return 'lampada ' + self.colore

a = Lampada('rossa')
b = Lampada('blu')
a.accendi()
print(a.descrivi(), a.accesa)
print(b.descrivi(), b.accesa)
Output 
lampada rossa True
lampada blu False
Da ricordare
  • Ogni oggetto ha i suoi attributi: accendere a non cambia b.
  • return restituisce un valore a chi ha chiamato il metodo; solo print lo fa comparire sullo schermo.
  • print(x, y) stampa i due valori sulla stessa riga, separati da uno spazio.
  • Un confronto come a == b o a < b vale True oppure False.

2 Incapsulamento

Incapsulare significa proteggere lo stato dell'oggetto: i dati si modificano solo attraverso i metodi della classe, che possono controllare che i valori abbiano senso.

Un attributo che inizia con due underscore, come self.__valore, è privato: si usa solo dentro la classe, tramite self. Dall'esterno si passa dai metodi: il get per leggere, il set per modificare.

Esempio 
class Voto:
    def __init__(self):
        self.__valore = 6

    def set_valore(self, v):
        if v < 1:
            v = 1
        if 10 < v:
            v = 10
        self.__valore = v

    def get_valore(self):
        return self.__valore

    def aumenta(self, punti):
        self.set_valore(self.__valore + punti)

v = Voto()
v.set_valore(12)
print(v.get_valore())
v.set_valore(7)
v.aumenta(2)
print(v.get_valore())
Output 
10
9

Un metodo può anche rifiutare un'operazione e comunicarlo restituendo True o False. Quando incontra return, il metodo termina subito: le righe successive non vengono eseguite.

class Zaino:
    def __init__(self):
        self.__peso = 0

    def aggiungi(self, kg):
        if 10 < self.__peso + kg:
            return False
        self.__peso = self.__peso + kg
        return True

    def get_peso(self):
        return self.__peso

z = Zaino()
print(z.aggiungi(6))
print(z.aggiungi(6))
print(z.get_peso())
Output 
True
False
6
Da ricordare
  • Il set è il posto giusto per i controlli: l'oggetto non finisce mai in uno stato non valido.
  • Un metodo può chiamare un altro metodo della stessa classe con self.nome_metodo(...): in aumenta il controllo del set viene riusato.
  • Gli attributi privati si leggono e si modificano solo dentro la classe; da fuori si usano i metodi.

3 Ereditarietà e super()

Con class Studente(Persona): la classe Studente eredita attributi e metodi di Persona e può aggiungerne di nuovi. Uno studente è una persona.

super() permette di chiamare un metodo della classe base. Si usa soprattutto nel costruttore: super().__init__(...).

Esempio 
class Persona:
    def __init__(self, nome):
        self.nome = nome

    def saluta(self):
        return 'Ciao, sono ' + self.nome

class Studente(Persona):
    def __init__(self, nome, classe):
        super().__init__(nome)
        self.classe = classe

    def studia(self):
        return self.nome + ' studia in ' + self.classe

s = Studente('Luca', '4C')
print(s.saluta())
print(s.studia())
Output 
Ciao, sono Luca
Luca studia in 4C

Dove cerca Python un metodo?

Per eseguire s.saluta() Python guarda prima nella classe dell'oggetto (Studente). Se non trova il metodo sale alla classe base (Persona), poi alla base della base, e così via. Se non lo trova da nessuna parte segnala AttributeError.

La ricerca va solo verso l'alto: un metodo aggiunto nella sottoclasse (studia) non esiste per un oggetto Persona.

L'ordine delle istruzioni conta

Le istruzioni di __init__ vengono eseguite nell'ordine in cui sono scritte, prima e dopo la chiamata a super(). Se lo stesso attributo viene assegnato più volte, vale l'ultima assegnazione eseguita.

class Base:
    def __init__(self):
        print('inizio Base')
        self.x = 1

class Figlia(Base):
    def __init__(self):
        print('inizio Figlia')
        super().__init__()
        print('fine Figlia', self.x)

f = Figlia()
Output 
inizio Figlia
inizio Base
fine Figlia 1
Attenzione
  • Se la sottoclasse scrive un proprio __init__, quello della base non parte da solo: gli attributi creati lì esistono solo se chiami super().__init__(...).
  • Se la sottoclasse non scrive __init__, viene usato quello della base, con i suoi parametri.

4 Polimorfismo

Polimorfismo significa che la stessa chiamata, per esempio p.costo(100), esegue codice diverso a seconda del tipo reale dell'oggetto. Si ottiene con l'override: la sottoclasse riscrive un metodo della base con lo stesso nome.

Sostituire o estendere un metodo

class Pagamento:
    def costo(self, prezzo):
        return prezzo

class ConSconto(Pagamento):
    def costo(self, prezzo):
        return prezzo - 10

class ConSpedizione(Pagamento):
    def costo(self, prezzo):
        return super().costo(prezzo) + 5

for p in [Pagamento(), ConSconto(), ConSpedizione()]:
    print(p.costo(100))
Output 
100
90
105

ConSconto sostituisce il metodo della base. ConSpedizione lo estende: chiama la versione della base con super() e aggiunge qualcosa. Se ogni livello di una gerarchia fa così, le chiamate a super() si concatenano dal basso verso l'alto.

Un metodo ereditato che chiama self.altro_metodo()

Anche se un metodo è scritto nella classe base, self è sempre l'oggetto reale. Per questo self.canale() usa la versione della classe dell'oggetto, se esiste.

class Messaggio:
    def invia(self):
        return '[' + self.canale() + '] inviato'

    def canale(self):
        return 'email'

class Sms(Messaggio):
    def canale(self):
        return 'sms'

print(Messaggio().invia())
print(Sms().invia())
Output 
[email] inviato
[sms] inviato

Duck typing: conta il metodo, non la famiglia

In Python due classi senza nessuna base in comune possono essere usate allo stesso modo, purché abbiano il metodo richiesto. Python non controlla i tipi in anticipo: se il metodo manca, l'errore arriva solo nel momento della chiamata.

class Gatto:
    def verso(self):
        return 'Miao'

class Sveglia:
    def verso(self):
        return 'Driin'

for x in [Gatto(), Sveglia()]:
    print(x.verso())
Output 
Miao
Driin
Da ricordare
  • Per sapere quale metodo parte, chiediti: di che classe è davvero l'oggetto? La ricerca parte da lì.
  • Una sottoclasse che non riscrive un metodo usa quello ereditato.
  • super().metodo() esegue la versione della classe base, poi il risultato può essere completato.

5 Quando il programma si ferma: gli errori

Quando un'istruzione non si può eseguire, Python solleva un errore e il programma si ferma in quella riga. Le righe stampate prima restano sullo schermo; quelle dopo non vengono eseguite.

ErroreQuando capita (nel quiz)
AttributeErrorL'oggetto non ha l'attributo o il metodo richiesto: l'attributo non è mai stato creato, per esempio perché manca super().__init__(...), oppure il metodo esiste solo in un'altra classe.
TypeErrorUna chiamata ha il numero sbagliato di argomenti, per esempio un costruttore che ne vuole due e ne riceve uno.
 
class Punto:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Punto(1, 2)
print(p.x)
print(p.z)
print('fine')
Output 
1
Errore: AttributeError
Nel quiz Un'opzione come 1 seguito da Errore: AttributeError significa: il programma ha stampato 1, poi si è fermato con quell'errore. Infatti 'fine' non compare.
