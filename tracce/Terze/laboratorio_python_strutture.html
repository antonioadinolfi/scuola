In Python un vettore si rappresenta con una lista monodimensionale e una matrice con una lista di liste. Gli indici partono da 0. Le tuple, a differenza delle liste, sono immutabili. Il pulsante “Esegui” prova il codice senza valutarlo; “Verifica soluzione” controlla i casi previsti, compresi alcuni casi limite. Il motore Skulpt implementa Python nel browser, ma non tutte le librerie CPython sono supportate.
