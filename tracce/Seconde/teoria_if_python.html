1 Variabili e assegnazione

Una variabile è un nome che contiene un valore. Con = le si assegna un valore: Python calcola prima tutto ciò che sta a destra, poi lo salva nella variabile a sinistra.

Esempio 
x = 2
y = x * 3
x = x + 1
print(x, y)
Output 
3 6
Da ricordare
  • Le istruzioni vengono eseguite dall'alto verso il basso, una alla volta.
  • y = x * 3 usa il valore che x ha in quel momento: se poi x cambia, y non cambia.
  • x = x + 1 significa: prendi il valore attuale di x, aggiungi 1, salva il risultato in x.
  • print(a, b) stampa i due valori sulla stessa riga, separati da uno spazio.

  • Un numero è pari se n % 2 == 0; in generale a è divisibile per b se a % b == 0.

3 Confronti e operatori logici: and, or, not

Ogni condizione, alla fine, vale True (vera) oppure False (falsa). Le condizioni semplici sono i confronti; con gli operatori logici si uniscono più confronti in una condizione sola.

I confronti

Attenzione: = assegna un valore, == confronta due valori.

ScritturaSi legge
a == b · a != ba uguale a b · a diverso da b
a < b · a <= ba minore di b · a minore o uguale a b
a > b · a >= ba maggiore di b · a maggiore o uguale a b

Le tavole di verità

Ogni operatore logico ha una regola precisa, che si riassume in una tavola di verità: per ogni combinazione di valori di A e B dice il risultato.

ABA and BA or B
TrueTrueTrueTrue
TrueFalseFalseTrue
FalseTrueFalseTrue
FalseFalseFalseFalse
Anot A
TrueFalse
FalseTrue
Come ricordarle
  • and («e»): è vera solo se tutte e due le condizioni sono vere. Basta una falsa per renderla falsa.
  • or («oppure»): è vera se almeno una è vera, anche se lo sono tutte e due. È falsa solo se sono false entrambe.
  • not («non»): rovescia il valore: il vero diventa falso e il falso diventa vero.
a = True
b = False
print(a and b, a or b, not a)
Output 
False True False

Come si calcola una condizione lunga

Python calcola una condizione in quest'ordine: prima i calcoli (+ - * / // %), poi i confronti, poi not, poi and, e per ultimo or. Le parentesi cambiano l'ordine: quello che sta tra parentesi si calcola per primo.

x = 6
print(x > 5 or x > 3 and x < 0)
print((x > 5 or x > 3) and x < 0)
Output 
True
False

Nella prima riga, senza parentesi, Python calcola prima l'and: x > 3 and x < 0 vale True and False, cioè False. Resta x > 5 or False, cioè True or False, che vale True. Nella seconda riga le parentesi fanno calcolare prima l'or (True), e poi True and False dà False.

Il metodo per non sbagliare
  • Calcola ogni confronto e scrivi sopra True o False.
  • Risolvi le parentesi, poi i not, poi gli and, infine gli or.
  • Quando scrivi tu una condizione che mescola and e or, metti le parentesi: il codice diventa più chiaro e fa quello che intendi.

not davanti a una parentesi

Il not davanti a una parentesi rovescia il risultato di tutta la parentesi. Si può anche portarlo dentro, ma allora and e or si scambiano (leggi di De Morgan):

Questa condizione……equivale a
not (A and B)not A or not B
not (A or B)not A and not B
 
sole = True
caldo = False
print(not (sole and caldo), not sole or not caldo)
print(not (sole or caldo), not sole and not caldo)
Output 
True True
False False

Intervalli: dentro e fuori

Per dire che un numero sta dentro un intervallo servono due confronti uniti da and. Per dire che sta fuori se ne usano due uniti da or, con i confronti rovesciati.

t = 37
if t >= 36 and t <= 37.5:
    print('normale')
if t < 36 or t > 37.5:
    print('da controllare')
Output 
normale
Errori tipici
  • x > 5 and < 10 è un errore: ogni lato di and e or deve essere un confronto completo. Si scrive x > 5 and x < 10.
  • giorno == 'sabato' or 'domenica' non controlla la domenica: Python non dà errore ma la condizione risulta sempre vera. Si scrive giorno == 'sabato' or giorno == 'domenica'.
  • or non vuol dire «o l'uno o l'altro, ma non tutti e due»: se sono vere entrambe, or è vero.
  • Una variabile che vale già True o False si usa direttamente: if pioggia: e if not pioggia:, senza == True.
La forma corretta del secondo errore 
giorno = 'domenica'
if giorno == 'sabato' or giorno == 'domenica':
    print('weekend')
else:
    print('giorno feriale')
Output 
weekend

4 if ed else

Con if il programma esegue un blocco di righe solo se la condizione è vera. Il blocco else, se c'è, viene eseguito quando la condizione è falsa. Le righe del blocco sono rientrate di 4 spazi.

altezza = 135
if altezza >= 140:
    print('puoi salire')
else:
    print('troppo basso')
print('fine')
Output 
troppo basso
fine

Un if senza else non fa nulla quando la condizione è falsa, e il programma prosegue.

5 if / elif / else

Quando i casi sono più di due si usa elif («altrimenti se»). Python controlla le condizioni dall'alto verso il basso: esegue il blocco della prima condizione vera e salta tutte le altre, anche se sarebbero vere. Se nessuna è vera, esegue else.

punti = 85
if punti >= 90:
    print('oro')
elif punti >= 70:
    print('argento')
elif punti >= 50:
    print('bronzo')
else:
    print('nessuna medaglia')
Output 
argento
Attenzione all'ordine
  • 85 è anche maggiore di 50, ma 'bronzo' non viene stampato: dopo la prima condizione vera la catena finisce.
  • Con soglie come queste si parte dalla condizione più restrittiva. Se la prima fosse punti >= 50, chiunque arrivi a 50 prenderebbe il bronzo, anche con 95 punti.

6 if in sequenza e if annidati

Due if separati non sono un elif

Due if scritti uno sotto l'altro sono indipendenti: il secondo viene controllato in ogni caso, anche se il primo era vero. Se il primo blocco cambia una variabile, il secondo vede il valore nuovo.

n = 12
if n % 2 == 0:
    print('pari')
if n % 3 == 0:
    print('multiplo di 3')
k = 5
if k < 10:
    k = k + 10
if k > 12:
    k = 0
print(k)
Output 
pari
multiplo di 3
0

Un if dentro un altro

Un if può stare dentro il blocco di un altro if (rientrato di altri 4 spazi): viene controllato solo se la condizione esterna è vera.

eta = 16
accompagnato = True
if eta < 18:
    if accompagnato:
        print('entra con un adulto')
    else:
        print('non entra')
else:
    print('entra')
Output 
entra con un adulto

7 Come tracciare e come scrivere un algoritmo

Per prevedere che cosa stampa un programma

  1. Prepara una tabella con una colonna per ogni variabile.
  2. Esegui le righe una alla volta, dall'alto: a ogni assegnazione scrivi il nuovo valore nella tabella.
  3. A ogni if calcola la condizione con i valori attuali e segui solo il ramo giusto.
  4. In una catena if / elif / else fermati alla prima condizione vera.
  5. Scrivi l'output esattamente: con / il risultato ha il punto decimale.

Per scrivere un algoritmo con le condizioni

  1. Elenca tutti i casi possibili e che cosa deve succedere in ognuno.
  2. Traduci ogni caso in una condizione con ==, !=, <, >, %, unendo le parti con and e or.
  3. Scegli l'ordine: prima i casi più particolari, poi quelli più generali, e in fondo l'else.
  4. Prova l'algoritmo a mano con almeno un valore per ogni ramo, compresi i valori al confine (per esempio esattamente 18 in eta >= 18).
Esempio: segno di un numero (tre casi) 
n = -3
if n > 0:
    print('positivo')
elif n < 0:
    print('negativo')
else:
    print('zero')
Output 
negativo
