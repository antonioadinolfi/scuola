1 Variabili e assegnazione

Una variabile è un nome che contiene un valore. Con = le si assegna un valore: Python calcola prima tutto ciò che sta a destra, poi lo salva nella variabile a sinistra.

Esempio 
x = 2
y = x * 3
x = x + 1
print(x, y)
Output 
3 6
Da ricordare
  • Le istruzioni vengono eseguite dall'alto verso il basso, una alla volta.
  • y = x * 3 usa il valore che x ha in quel momento: se poi x cambia, y non cambia.
  • x = x + 1 significa: prendi il valore attuale di x, aggiungi 1, salva il risultato in x.
  • print(a, b) stampa i due valori sulla stessa riga, separati da uno spazio.

3 Confronti, and, or, not

Un confronto vale True (vero) oppure False (falso). Attenzione: = assegna, == confronta.

ScritturaSi legge
a == b · a != ba uguale a b · a diverso da b
a < b · a <= ba minore di b · a minore o uguale a b
a > b · a >= ba maggiore di b · a maggiore o uguale a b
c1 and c2vero solo se entrambe le condizioni sono vere
c1 or c2vero se almeno una delle due è vera
not cil contrario di c
 
a = 4
print(a > 2 and a < 10)
print(a == 5 or a < 0)
print(not a == 4)
Output 
True
False
False
Da ricordare
  • Per dire «x è tra 1 e 10» servono due confronti uniti da and: x >= 1 and x <= 10.
  • Una variabile che vale True o False si può usare direttamente come condizione: if pioggia:.

4 if ed else

Con if il programma esegue un blocco di righe solo se la condizione è vera. Il blocco else, se c'è, viene eseguito quando la condizione è falsa. Le righe del blocco sono rientrate di 4 spazi.

altezza = 135
if altezza >= 140:
    print('puoi salire')
else:
    print('troppo basso')
print('fine')
Output 
troppo basso
fine

Un if senza else non fa nulla quando la condizione è falsa, e il programma prosegue.

5 if / elif / else

Quando i casi sono più di due si usa elif («altrimenti se»). Python controlla le condizioni dall'alto verso il basso: esegue il blocco della prima condizione vera e salta tutte le altre, anche se sarebbero vere. Se nessuna è vera, esegue else.

punti = 85
if punti >= 90:
    print('oro')
elif punti >= 70:
    print('argento')
elif punti >= 50:
    print('bronzo')
else:
    print('nessuna medaglia')
Output 
argento
Attenzione all'ordine
  • 85 è anche maggiore di 50, ma 'bronzo' non viene stampato: dopo la prima condizione vera la catena finisce.
  • Con soglie come queste si parte dalla condizione più restrittiva. Se la prima fosse punti >= 50, chiunque arrivi a 50 prenderebbe il bronzo, anche con 95 punti.

6 if in sequenza e if annidati

Due if separati non sono un elif

Due if scritti uno sotto l'altro sono indipendenti: il secondo viene controllato in ogni caso, anche se il primo era vero. Se il primo blocco cambia una variabile, il secondo vede il valore nuovo.

n = 12
if n % 2 == 0:
    print('pari')
if n % 3 == 0:
    print('multiplo di 3')
k = 5
if k < 10:
    k = k + 10
if k > 12:
    k = 0
print(k)
Output 
pari
multiplo di 3
0

Un if dentro un altro

Un if può stare dentro il blocco di un altro if (rientrato di altri 4 spazi): viene controllato solo se la condizione esterna è vera.

eta = 16
accompagnato = True
if eta < 18:
    if accompagnato:
        print('entra con un adulto')
    else:
        print('non entra')
else:
    print('entra')
Output 
entra con un adulto

7 Come tracciare e come scrivere un algoritmo

Per prevedere che cosa stampa un programma

  1. Prepara una tabella con una colonna per ogni variabile.
  2. Esegui le righe una alla volta, dall'alto: a ogni assegnazione scrivi il nuovo valore nella tabella.
  3. A ogni if calcola la condizione con i valori attuali e segui solo il ramo giusto.
  4. In una catena if / elif / else fermati alla prima condizione vera.
  5. Scrivi l'output esattamente: con / il risultato ha il punto decimale.

Per scrivere un algoritmo con le condizioni

  1. Elenca tutti i casi possibili e che cosa deve succedere in ognuno.
  2. Traduci ogni caso in una condizione con ==, !=, <, >, %, unendo le parti con and e or.
  3. Scegli l'ordine: prima i casi più particolari, poi quelli più generali, e in fondo l'else.
  4. Prova l'algoritmo a mano con almeno un valore per ogni ramo, compresi i valori al confine (per esempio esattamente 18 in eta >= 18).
Esempio: segno di un numero (tre casi) 
n = -3
if n > 0:
    print('positivo')
elif n < 0:
    print('negativo')
else:
    print('zero')
Output 
negativo
